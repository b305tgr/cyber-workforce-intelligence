PRIVATE WI-FI

Connect your phone

Start a temporary connection, then scan the QR code with your phone camera. Keep both devices on the same trusted Wi-Fi.

Phone cannot connect?
  1. Connect both devices to the same non-guest Wi-Fi network.
  2. In Windows, set this trusted Wi-Fi network to Private: Settings → Network & internet → Wi-Fi → your network → Network profile type.
  3. Allow Python/Midnight Signal through Windows Firewall on Private networks only. Do not turn the firewall off.
  4. Guest Wi-Fi or router client isolation can block devices from reaching each other.

Each QR code contains a private, temporary access key. Don’t share it or use public Wi-Fi. Access stops when you turn it off or close Midnight Signal.
