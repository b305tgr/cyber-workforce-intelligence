A little more signal, a little less noise

Powerful tools.
On your terms.

Midnight Signal is a local-first AI studio for building, exploring, and understanding. Bring your own Ollama models and work with your projects without sending everyday prompts to a hosted AI service.

01 / LOCAL BY DESIGN

Your model, your machine

Midnight Signal connects to Ollama running on your computer. Choose the model that fits the task and keep your normal chat and coding workflow on-device.

02 / MAKE THINGS

From idea to project

Use the coding agent to inspect a workspace, create and edit project files, run checks, and package multi-file website work for download.

03 / READ DEEPLY

Documents with context

Attach supported documents to ask questions about their contents. PDF text extraction, optional local OCR, and private EmbeddingGemma-assisted retrieval help with longer material when that model is installed.

04 / KEEP THE WHEEL

Review before changes

Choose how the coding agent handles approvals. Inspect workspace changes and use supported undo actions instead of handing over an invisible process.

TRANSPARENT BY DEFAULT

Local chat stays local.
Web research is a choice.

Requests are sent to your configured local Ollama service. If you ask the agent to search the web, it can access public sources; that activity is shown in the conversation.
