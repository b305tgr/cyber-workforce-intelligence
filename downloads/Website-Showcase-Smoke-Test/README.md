# Serein House – Boutique Coastal Hotel
A polished multi-page website showcasing a fictional coastal retreat.

## Local Run Instructions
1. Open `index.html` in any modern browser (Chrome, Firefox, Safari).
2. No server required—all assets are self-contained.
3. Test responsiveness by resizing the window or using mobile device emulation.
4. Forms and navigation are fully functional for local testing.

## Features
- Responsive design with mobile-first approach
- Custom SVG/CSS hero artwork
- Semantic HTML5, ARIA landmarks, and keyboard accessibility
- Reduced-motion support (prefers-reduced-motion)
- Local-only booking form validation
- No external dependencies

## Files Included
- `index.html` – Homepage with hero, rooms, experiences, testimonials
- `rooms.html` – Detailed room listings with filters
- `experiences.html` – Categorized activities and bookings
- `visit.html` – Arrival info, contact form, map illustration
- `assets/styles.css` – Premium editorial design system
- `assets/site.js` – Interactive elements (filters, mobile menu)

## Design System
- Palette: Deep ocean (#1a3e5c), warm sand (#f4d0a6), sea-glass (#8fa7b3), coral (#ff8a65)
- Type scale: Editorial hierarchy with custom SVG icons
